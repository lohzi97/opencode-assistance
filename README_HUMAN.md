### Install opencode-assistant

```bash
./install.sh
```

### Configure opencode-assistant

```bash
./config.sh
```

Re-run `./config.sh` any time you need to update:
- Brave Search API key
- Telegram Ping bot token or chat ID
- OpenCode provider login

### Start opencode-assistant

```bash
./start.sh
```
