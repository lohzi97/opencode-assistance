Run the `prioritize-tasks` skill, then run the monthly recalibration.

## Steps

1. Load `~/obsidian/Todo Ledger.md`, `notes/master/ideal-life-vision.md`, and `notes/master/goal-roadmap.md`.
2. Review the past month: what progressed, what stalled, what was added or removed, what's been sitting stale.
3. Ask Master (conversationally, one thread at a time):
   - How do you feel about the ledger and the current priorities?
   - Has anything drifted — new constraints, opportunities, relationship / career / health / financial changes?
   - Any goals in the vision or roadmap that need updating?
4. Apply changes together: re-tag priorities, add new items, close/archive stale ones, then refresh **Focus This Week** for the coming week (hand off to the weekly-focus logic).

## Guardrails

5. If the vision or roadmap needs edits, **propose** them — do not silently change locked docs. Flag for Master's explicit confirmation.
6. Commit + push the ledger (obsidian vault mandate).
7. Summarize: what changed this month, and any open items flagged for the next life-goals or financial-goals session.

Tone: this is a reflective check-in, not a task list dump. Lead with how Master feels about the plan, then adjust.
